# Standby-Fan-Patcher
 Make your Wii's fan run while in standby!

# Disclaimer :

This tool writes to the NAND, so use it at your own risk!

This tool is specifically made for Wiis that overheat in standby (A.K.A early revisions), you may not want to use this if your Wii was made past 2008 or so (unless it heats a lot in standby).

# How to use :

Open the app & press either A to patch or B to revert.
